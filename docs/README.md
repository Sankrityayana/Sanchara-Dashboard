## What This Project Demonstrates

Sanchar Dashboard demonstrates a practical real-time telemetry pipeline:

- a stateful vehicle simulator
- live WebSocket streaming
- frontend local vehicle tracking
- health scoring and alerts
- scenario controls for demoing failure modes
- optional time-series persistence with InfluxDB
- REST APIs for fleet state and automation
- Docker, CI, tests, and deployment readiness
