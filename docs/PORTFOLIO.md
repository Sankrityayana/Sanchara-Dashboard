# Portfolio Notes

## Project Title

Sanchar Dashboard - Real-Time Vehicle Telemetry Dashboard

## Short Description

Built a deployed real-time EV telemetry dashboard using React, TypeScript, Node.js, WebSockets, and InfluxDB to simulate, stream, track, and visualize fleet telemetry with health scoring, alerts, scenario controls, and local vehicle tracking.

## Resume Bullets

- Engineered a real-time EV telemetry dashboard streaming WebSocket data for 3 simulated vehicles with live speed, battery, temperature, range, health, and alert tracking.
- Built 5 vehicle scenario workflows for low battery, overheating, charging, offline, and recovery states to validate real-time telemetry and fault-monitoring behavior.
- Deployed a cloud-ready full-stack system with React, TypeScript, Node.js, REST APIs, WebSockets, Docker support, CI checks, and optional InfluxDB persistence.

## LinkedIn Caption

I built Sanchar Dashboard, a real-time EV telemetry dashboard that streams mock vehicle data over WebSockets and visualizes fleet health live. It includes a coherent vehicle simulator, health scoring, alerts, local vehicle tracking, scenario controls, optional InfluxDB persistence, REST APIs, Docker, CI, and cloud deployment.

Tech stack: React, TypeScript, Node.js, WebSockets, InfluxDB, Docker, GitHub Actions, Vercel, Render.
