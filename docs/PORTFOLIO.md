# Portfolio Notes

## Project Title

Sanchar Dashboard - Real-Time Vehicle Telemetry Dashboard

## Short Description

Built a real-time EV telemetry dashboard using React, TypeScript, Node.js, WebSockets, and InfluxDB to simulate, stream, track, and visualize fleet telemetry with health scoring, alerts, scenario controls, and local vehicle tracking.

## Resume Bullets

- Built a real-time EV telemetry dashboard with React, TypeScript, Node.js, and WebSockets.
- Designed a stateful mock vehicle simulator with coherent speed, battery, range, power, temperature, location, and health values.
- Implemented scenario controls for normal, low-battery, overheating, charging, and offline states.
- Added local vehicle tracking with online/offline state, last-seen time, sample counts, and vehicle comparison.
- Integrated optional InfluxDB support for time-series telemetry persistence and historical queries.
- Added REST APIs, Docker Compose, GitHub Actions CI, and tests for simulator behavior.

## LinkedIn Caption

I built Sanchar Dashboard, a real-time EV telemetry dashboard that streams mock vehicle data over WebSockets and visualizes fleet health live. It includes a coherent vehicle simulator, health scoring, alerts, local vehicle tracking, scenario controls, optional InfluxDB persistence, REST APIs, Docker, and CI.

Tech stack: React, TypeScript, Node.js, WebSockets, InfluxDB, Docker, GitHub Actions.
